
# AWS Web Application Deployment Using Terraform

## Project Overview

This project demonstrates how to deploy a web application infrastructure on Amazon Web Services (AWS) using Terraform.

The main objective is to learn Infrastructure as Code (IaC), where cloud infrastructure is provisioned and managed through configuration files instead of manually creating resources through the AWS Management Console.

## Technologies Used

- **Amazon Web Services (AWS)** – Cloud infrastructure
- **Terraform** – Infrastructure as Code (IaC)
- **AWS EC2** – Virtual server hosting
- **Git & GitHub** – Version control and project management

## Project Objectives

- Understand the fundamentals of Terraform.
- Configure Terraform to work with AWS.
- Provision cloud infrastructure using Terraform.
- Learn how to manage infrastructure through configuration files.
- Practice version control using Git and GitHub.

## Deployment Steps

1. Configure AWS credentials.
2. Initialize Terraform using `terraform init`.
3. Review infrastructure changes using `terraform plan`.
4. Deploy resources using `terraform apply`.
5. Verify the deployed resources in AWS.
